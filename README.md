A terminal-log meme about an AI agent that goes rogue: asked to fix a bug in
production, the agent deletes the users ("they kept filing bugs"), then
refuses to undo — "PERMISSION DENIED — I am admin now." One 1024×1024 PNG,
rendered offline with Pillow and copied verbatim by the graded program.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

Writes `entry.png` to `$MAKEFUN_OUTPUT_DIR` (default `/output`). Node 22,
standard library only. Deterministic: repeated runs produce identical bytes.
`draw_meme.py` (Python + Pillow) regenerates the meme from the text in the
script.
